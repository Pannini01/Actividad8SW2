Gestión de Drones - Arquitectura Hexagonal

Aplicación Java 17 + JavaFX + PostgreSQL organizada con Ports and Adapters.

Conserva CRUD, Observer y Chain of Responsibility para clima.

Strategy calcula consumo energético desde una ruta JSON usando Haversine y tres estrategias.

Command programa tareas de misión mediante comandos wrapper; DroneOperacionService actúa como Receiver y ProgramadorTareas como Invoker.

Las seis clases originales del modelo de drones permanecen sin modificaciones.
