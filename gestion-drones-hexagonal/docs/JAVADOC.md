# Javadoc

El proyecto contiene Javadoc en las clases públicas de dominio, puertos de entrada/salida, servicios, infraestructura, UI y `vista.App`.

Para regenerarlo:

```bash
mvn javadoc:javadoc
```

Salida Maven: `target/site/apidocs/index.html`.

Además se incluye una copia generada en `docs/javadoc/index.html`.
