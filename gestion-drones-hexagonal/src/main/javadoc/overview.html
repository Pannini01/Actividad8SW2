Gestión de Drones - Arquitectura Hexagonal

Aplicación Java 17 + JavaFX + PostgreSQL organizada con Ports and Adapters.

La solución separa cada caso de uso mediante un puerto de entrada y un servicio de aplicación individual. El puerto de salida DronRepository es implementado por DronPostgresAdapter.

vista.App funciona como composition root: crea el adaptador de salida, construye los servicios y los inyecta en el adaptador de entrada JavaFX ui.DronController.

Los únicos patrones de diseño intencionales son Adapter para PostgreSQL y Singleton para la conexión JDBC.
