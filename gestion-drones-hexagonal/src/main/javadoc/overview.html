Gestión de Drones - Arquitectura Hexagonal

Aplicación académica Java 17 + JavaFX + PostgreSQL organizada con Ports and Adapters.

Conserva CRUD, Observer, Chain of Responsibility, Strategy y Command.

State: administra el ciclo APAGADO → EN ESPERA → VOLANDO → ATERRIZANDO mediante DroneState, sus estados concretos y un Context interno, sin modificar la entidad Dron.

Mediator: MissionCoordinator centraliza NavigationSystem, SensorSystem, BatterySystem y CommunicationSystem; los componentes no se comunican directamente y la funcionalidad no utiliza el CRUD de drones.

Las seis clases originales del modelo permanecen sin modificaciones.

Las pruebas JUnit incluyen pruebas unitarias y pruebas de integración ejecutables mediante Maven Surefire/Failsafe.

State: DroneState funciona como wrapper abstracto de Dron; no existe DroneStateContext.
